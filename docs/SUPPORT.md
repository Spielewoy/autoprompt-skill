# Support

Autoprompt is community maintained, with no guaranteed response time.

## Check first

- Read the [README](../README.md), [FAQ](faq/), and [supported client list](faq/which-coding-agents-are-supported.md).
- Save the output from:

  ```console
  autoprompt doctor <client> --strict
  ```

## Open an issue

Use a bug report for a reproducible problem in a supported client. Include the Autoprompt version or commit, client version, operating system, install method, doctor output, and minimal reproduction. Remove secrets and personal data.

Use a feature request for a specific improvement. Use a benchmark request for a reproducible comparison with a public harness. Reports without enough detail may be closed.

Report suspected vulnerabilities through the [security policy](SECURITY.md), not the issue tracker.
